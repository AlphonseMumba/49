# 49
Le 49 est un jeu de cartes tactique basé sur le contrôle d'un score commun au centre de la table. L'objectif de chaque joueur est d'utiliser les cartes de sa main pour modifier la valeur du terrain tout en évitant de dépasser le seuil maximal de 49. Le dernier joueur à ne pas dépasser cette limite remporte la manche.
